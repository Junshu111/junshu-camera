# Junshu 相机｜当前完整外壳与内部结构安装说明
整理日期：2026年10月28日

本说明适用于当前 125 × 78 × 106 mm 主壳、4.3英寸屏幕、树莓派3B+、Camera Module 2、48 × 42 × 18 mm 电池及隐藏下拨机构。

使用的组合是：现有主壳和共用零件＋加固树莓派支架/新电池固定件＋前移镜头固定件＋已能正常下拨的A方案。拨杆校准件尚未确定最佳编号，单独放在附件中。

## 一、先找到正确的文件

1. 01_当前完整模型：一份完整3MF，以及50个当前组合的STL。
   50个文件中包含B/C两种外拨杆、充电口可选垫片和拆卸工具，不是50件都要装进相机。B/C只装一个，垫片按配合选择，17号拆卸拨片是工具。
2. 02_拨杆校准附件_待选档：最新版6个校准件，三只U形卡环、三只圆盘。每组每次只装一只，尚未默认选择任何新档位。
3. 零件与复用清单.csv：每个零件的当前文件名、用途、版本和复用选择。
4. 03_装配源文件与打印预设：当前组合的毫米装配坐标和打印参数，用于后续修改与核对。
5. 04_当前零件图示、05_实物与尺寸依据：辅助对照。

总包只提供当前有效模型和必要资料，不包含历史制造版本、作废候选或旧试验包。

## 二、打印顺序

完整3MF已按拓竹X2D、0.4mm喷嘴、PETG Matte、纹理PEI板排好三盘。

第1盘：12个更新件，包括加固Pi支架、电池托盘、上梁、三根长锁销、两片镜头框架、镜头侧的长固定座/长锁键，以及A方案盒架和圆盘。
第2盘：36个共用件，包括屏幕压框、固定鞋、小卡销、外拨杆、按钮垫圈、充电口组件等。已有且完好的按清单跳过。
第3盘：现有主壳与底盖的备份模型。你已有这两个零件时跳过；本次不要求重印主壳。

如果从零开始、手边没有主壳，可先打印第3盘；如果已有主壳，优先打印第1盘，再补齐第2盘缺件。

整盘切片估计：第1盘约6小时03分、83.4g；第2盘约2小时56分、40.1g；第3盘约10小时46分、177.2g。这是把整盘所有对象都打印时的估计，包含可选件，不代表你现在需要全部重印。

完整模型保持0.16mm层高、首层0.20mm、4层墙、20% gyroid、外侧brim 5mm。普通自动支撑、紧贴、35°；仅在打印板生成关闭；上下Z距离0.24mm，XY间距0.35mm，顶部/底部接触面3/2层、接触面线距0.5mm；圆弧拟合关闭。保持100%比例和内置朝向。

拨杆校准附件单独使用0.12mm层高，让三种卡环厚度在切片后保持不同。不要把它改回完整模型的0.16mm。校准附件为一盘6件，约41分钟、6.46g，当前摆向切片没有生成支撑。

## 三、先整理零件

若机身已经合盖，先让树莓派正常关机并拔下外部充电线，再按第十六节托住底盖打开；露出机内MicroUSB供电接头后断开，之后才拆内部零件。机身尚未合盖时，先断开电池供电再组装。

剪小支撑再分段剥离，手扶厚底框和粗梁。不要抓着细孔座、弹片或长锁销的尖端扭整团支撑。

只清理brim、支撑和毛边。以下结构是模型本体，不能剪掉：
- 镜头框两侧带方孔的固定耳；
- 固定座和锁键上的加长操作柄；
- 树莓派支架的四个孔座及方形释放腔；
- 长锁销尖端的分叉、卡肩和弯折；
- 充电托架、滑盖与固定键上的弹舌和倒扣。

在台面把相应固定鞋、卡键、圆盘、方轴轻轻试配。遇阻先确认型号、方向、毛边，不用主壳当支点硬撬。完整机身主要由卡件固定，不需要新买螺丝或螺母；拨杆开关和电源按钮仍使用各自自带的金属螺母。

## 四、认识方向和几个容易混淆的名字

为方便说明，可把机身开口朝上，屏幕面朝下并用软垫保护。圆形镜头孔所在的侧壁叫“镜头前壁”。其余动作尽量以“朝屏幕”“朝底盖开口”“朝壳壁”“朝机身内部”描述。

10号固定鞋：安装到壳内导轨的小座，用来承托支架或框架。
11号锁键：穿入对齐的孔，防止对应支架退出。镜头01侧用新版长锁键，镜头02侧与电池6/7侧沿用对应短键。
36号长锁销：固定Pi支架的三根长销，替代旧11号短锁键03/04/05；不要在同一位置同时装新旧两种锁件。
14号Pi卡销：固定电路板四角的小销，不是36号长销。
34_rigid_cassette_withdrawal_key：拨杆盒架的刚性防退出锁键。
34_axial_shim、35_side_shim：充电口的可选垫片，与上面的34号锁键用途不同。按完整文件名分辨，不能只看数字34或35。
35_independent_button_washer_seat：电源按钮的独立打印垫圈。

## 五、先安装屏幕

1. 主壳保持空着，先把屏幕放入顶部对应的定位台阶。
2. 橙色排线及屏幕供电线从预留位置进入机身，不夹在屏幕边缘和壳壁之间。
3. 装入02屏幕压框，确认四边均匀落座。固定作用应落在屏幕边框/支承位置，不靠挤压玻璃。
4. 此时不要装Pi板、电池、Pi支架或底盖，先给镜头和固定件留出操作空间。

## 六、在台面组好镜头，再固定到主壳

本套使用05_camera_rear_clamp_forward_v29和06_camera_front_frame_forward_v29，两片必须成对使用。不要将旧05或旧06与这套混装。

1. 把Camera Module 2电路板放入06前定位框，镜头朝框中央开口，镜头下方黑色连接块进入专门留出的缺口。
2. 从电路板背后合上05后压框，对齐定位面。白色相机排线从预留开口离开，不夹在两框之间。
3. 沿原来的槽装回两只12镜头夹套，再分别插入13锁键。两侧方孔耳保留在外，用于连到主壳。
4. 把镜头总成从底盖开口放进机身。先与镜头前壁留约2.5mm距离，下放到镜头孔高度，再朝镜头孔方向靠回。不要让前移后的镜头贴着壳壁一路刮进去。
5. 靠壳角的01固定位置，使用10_camera_anchor_01_access_v29长固定座。握操作柄先向机身内部略让开下探，接近固定位置后再向壳角靠、对准导轨、降低并横向滑入固定耳；最后侧滑的名义距离约4.3mm。
6. 另一侧使用原10_anchor_shoe_02固定座。两侧都承托好后，01侧插新版11_camera_anchor_01_corner_key_v29长锁键；02侧插原11_anchor_key_02短锁键。
7. 新固定座和长锁键的操作柄留在机身里，不是支撑，不能剪断。另一侧短件要趁内部空着时安装，必要时用镊子辅助。
8. 检查镜头对准圆孔，两只固定耳都被托住、锁键到位，轻碰总成不会自行退出；白色排线不被夹住。

镜头组件独立固定在主壳上，不固定在Pi支架上。这套相对旧位置向外移动约2.1mm；模型中的方形镜头座前表面距壳外面约0.5mm，但真实圆镜筒突出量尚未精确量过，因此最后是否恰好齐平以实物为准，不能靠硬压镜头实现齐平。

镜头孔旁的阶梯形长孔沿用原通风开口，不承担这次新增的卡扣功能。

## 七、预放Pi支架的三只固定鞋，再下空支架

1. 先装10_anchor_shoe_03、04、05三只固定鞋，暂不装旧11号短锁键03/04/05。
2. 把03_pi_carrier_access_reinforced_v28空支架从底盖开口下放，落到三只固定鞋对应位置。
3. 此时Pi板、电池和电池上梁均先不装。扶着厚底框和粗侧架轻放，保留四个PCB承台、卡销孔及释放腔。
4. 暂不急着插三根长销；先装隐藏拨杆组件，尤其避免C位长销挡住拨杆盒架的进入路线。

## 八、安装隐藏拨杆与电源按钮

本套完整模型默认使用已经能正常下拨的A方案盒架A_down_25_cassette和原配对圆盘A_down_26_rotor。外拨杆B/C造型只选一个，二者共用内部接口。这里的外柄B/C造型与早前A/B方向诊断不是同一组编号，不要混淆。

1. 在台面把112-B1开关装到A25盒架，保持目前已经验证的自复位方向，用原金属螺母固定；不要靠扭动金属手柄改变开关本体的方向。带胶带的线根留在预留空腔。
2. 从机身内侧把盒架引向对应的三段壳内导轨入口，先比终位朝底盖开口方向高约8.5mm；向壳壁靠回后，再朝屏幕方向滑入导轨到位。三个舌片都必须入槽。
3. 安装29轴套；26圆盘从机身内侧配合到转轴位置；外部27拨杆从壳外将方轴插入圆盘方孔；最后装28 U形卡环卡住轴端原槽。方向沿用你目前已能正常操作的装法。
4. 插入34_rigid_cassette_withdrawal_key，挡住盒架朝开口方向退出的路线。这个锁键拆出时需要先抬起约2.6mm，再向机身内部让约6mm后取出，不能直拉穿过壳口边缘。
5. 轻拨外柄，检查圆盘能带动金属杆、松手能回位，线束不进入圆盘/叉口的扫动范围。两块固定止挡保留当前位置。
6. 电源按钮从壳外穿过对应圆孔，在壳内套入35_independent_button_washer_seat，用按钮自带螺母固定。保持原黄/黑等接线接法，不让带胶带的接头被垫圈或盒架挤住。

如果已在V30中选出了合适的F和T，可以用选中的F圆盘替换A26，用选中的T卡环替换28。没有选定前，先用当前能操作的原配圆盘和卡环作为基线。

## 九、用三根36号长销锁住Pi空支架

1. 36_long_lock_03与36_long_lock_04对应03/04两处固定鞋，按对应孔向屏幕方向插入到位。这两根形状相同，可按位置分配。
2. C位使用36_long_lock_05，其靠端部的弯折与前两根不同。
3. C销先从机身内部下探，在固定座上方约14mm处朝侧壁移动约9mm，对准后再向屏幕方向压入。实际遇阻时先核对方向和毛边。
4. 三根销的操作头都留在靠近底盖开口的位置。确认尖端卡肩通过对应的孔，不依赖随后合底盖来硬压固定。

## 十、先装空电池托盘，再放电池

1. 使用09_battery_cradle_open_end_v28空托盘。先向机身内部略偏，越过壳内原卡座，再靠回并落座。
2. 这一步先不装电池上梁的两只固定鞋6/7；它们提前装好会挡住电池/托盘的进入路线。
3. 电池按约48×42×18mm实物放置：48×42mm大面侧立，18mm薄边横向进入对应窄仓。新版仓内名义空间约49×43.15×19.2mm，不靠挤压蓝色外皮限位。
4. 把电池和两条软线单独放入空托盘。两条线朝开放出线槽的一端，线根跟随电池从上方进入，不卡在托盘底下。
5. 电池应由托盘承托，不直接压在Pi的USB/网口金属外壳上；这些不用的接口可以被遮挡，但不能作为电池固定支点。

## 十一、先放电池上梁，再侧入固定鞋

1. 把07_battery_bridge_side_entry_v28放到电池上方，保持自然余隙，不向电池外皮施压。
2. 将两只电池固定鞋6/7引到各自导轨入口，再从侧面横向滑入上梁下方。不要从顶部直接硬按固定鞋。
3. 最后插回原来的11_battery_anchor_key_6和7两只短锁键。
4. 此时Pi板仍未装入，便于手和工具操作。

## 十二、最后放Pi板、装四角小卡销并整理线

1. 让Pi板与60°的四个PCB承台平行，先略留出空隙，四个安装孔对上承台后再轻靠回。
2. 装回四只14_pi_clip_1/2/3/4小卡销，每个PCB孔对应一只。卡销过孔后检查板有托住，板底元件不直接顶支架。
3. 不要在壳外先把Pi锁死在支架上再整组硬塞；这会让电源插头、GPIO接头和电池互相挡住。
4. 橙色屏幕排线、白色相机排线，以及按钮/拉杆/屏幕供电线，沿用你已验证过的接口和接线位置。本说明调整机械固定与收线，不重新分配GPIO针脚；不能只按线的颜色推断针脚。
5. 必要的排线和杜邦插头可以在Pi最终归位前先接好，再把板轻靠回承台。卡锁要平行关好，杜邦头应完全插到原位置。
6. MicroUSB供电口保留插头黑胶壳约20—22mm的空间。先确认插头能插足，再让软线缓弯，不靠折弯插头根部来硬合壳。
7. 把多余软线分成松弯放在开放区域和长销内侧；白色与橙色排线不要折成尖锐死角。线和接头不进入拨杆、长销尖端或底盖扣合位置。
8. 先检查固定，再恢复电池供电测试；底盖暂不扣死。屏幕、相机、按钮和拨杆仍按原正常方案工作后，再继续合盖。

## 十三、在底盖上安装充电口和滑盖

先结束上一步的测试，让树莓派正常关机，再断开机内MicroUSB供电接头；外部充电线保持拔下。使用当前04_bottom_lid_recessed_usb-c底盖及30—33号配件，复用电池原来的Type-C充电母口和线，不增加充电电路。

1. 将30滑盖从底盖内侧放入轨道，指甲凹槽朝外，弹舌对准侧槽；托架尚未安装时先用手扶住滑盖。
2. Type-C母口从31托架内侧进入，小口朝底盖开孔，黑色塑料壳前端落在挡肩上。接头尺量暂按正面约12×5mm、轴向深约10mm，实物不顺就先检查方向与毛边。
3. 两条细线经过32后挡的U形缺口；后挡沿导槽滑到底，小弹舌进入凹槽。线不能夹在后挡边缘。
4. 如果接头前后松，可按需要放一片34_axial_shim；左右/薄边松时再按位置考虑35_side_shim。垫片是可选消隙件，不是全部叠上；后挡放不进去就不能靠用力挤接头。
5. 扶住滑盖，把31托架靠到正式底盖内侧，定位柱穿过对应窗口，再从横向入口插入两枚33固定键，直到卡肩越过定位柱背面。
6. 在不接充电电源时试插/拔充电线，确认母口不会被推进壳内，也不会随线被拉出；插头胶壳不顶开孔，金属头能插足。
7. 试开合滑盖，开、关都能到位；插着充电线时不关滑盖。
8. 充电线在壳内留足开启底盖的余量。开盖时托住底盖，不让它吊在电池线上。

## 十四、最后合盖与检查

1. 先正常关机、再断开机内供电，重新确认：镜头两侧固定座和锁键到位；Pi支架三根长销到位；电池上梁两鞋两键到位；拨杆盒架三处舌片和刚性防退出锁键到位；Pi四角小卡销到位。
2. 清出壳口、盖扣、充电托架后挡和拨杆运动区的软线。底盖自然靠上时应能落到原台阶，不用盖扣拉着盖子去压线或压电池。
3. 安装四只16_cover_clip_1/2/3/4到各自原位置，全部扣好。
4. 其中4号盖扣必须正确安装，因为它同时限制拨杆盒架刚性锁键退出；仅把盖子放上去不等于完成这处限位。
5. 检查镜头对孔、屏幕边框、充电滑盖；再恢复供电，检查正常画面、按钮、拨杆下拨触发和自动回位。
6. 最后轻轻变换机身方向，内部不应有明显元件窜动或零件掉落声。新固定件的保持力、实际公差和耐久尚需使用验证；这一步只能作为装配核对。

## 十五、拨杆校准件怎样选择

你已确认的主要虚位是“圆盘跟着转，金属杆暂时不动”。因此先试F组，后试T组。

F1/F2/F3是圆盘，分别把下叉接触面靠近金属杆0.10/0.15/0.20mm。
T1/T2/T3是U形卡环，总厚分别1.40/1.52/1.64mm。
两组都刻1、2、3条线作为编号，形状能区分是F还是T。

步骤：保持旧卡环不变，依次换F1、F2、F3，比较金属杆是否更早跟着动，以及松手是否完整回位。选好F后固定不变，再依次换T1、T2、T3，比较转轴前后窜动和转动顺畅度。每组只装一件，卡环不叠加。

合适的版本应同时满足：虚位更小、轻拨能触发、静止不持续压着金属杆、松手能自动完全回位。最厚/最紧的档位不一定最佳。相邻F档只差0.05mm，打印误差可能使手感接近，如实反馈“差不多”即可。

反馈例：“F2＋T1：虚位明显减少，拨动顺，松手全部回位，拍照正常；F3太紧。”

## 十六、以后拆卸时的顺序

已合盖时，先正常关机并拔下外部充电线。让底盖朝上，托住底盖后取下四只盖扣，轻轻打开，给充电尾线留出松弛量，不把底盖吊在线上。露出机内电池到Pi的MicroUSB供电接头后拔下，再拆Pi、电池或支架。4号盖扣卸下后，拨杆盒架的防退出锁键少了这处后备限位，因此开盖时先不要拨动外柄。

如果要拆C位Pi长销或拨杆盒架，先取出挡手的Pi、电池和上梁并移开软线。C位长销先朝开口方向抬约14mm，再向机身内部移约9mm，再抽出。A/B两根长销可按原轴向退出。

若只拆拨杆盒架，先按需要拆按钮及打印垫圈、U卡环、外柄、圆盘和轴套，释放刚性防退出锁键后，再让盒架沿导轨朝开口方向移动约8.5mm、向内让开后取出。不要在锁键或C长销仍挡着的时候硬拉盒架。

镜头框是独立固定，通常不用随Pi支架一起拆。拆镜头时先清出前方操作空间，再退出对应锁键和固定座，托住镜头总成，避免让它吊在白色排线上。

本说明依据当前CAD、切片检查和你已反馈的装配结果编写。新镜头框、长销、卡环/叉口选档的实际配合、回弹及长期耐久还需要实物确认。若某步明显遇阻，先停在该步，按完整零件名和照片反馈，不削止挡、不强压线束。
