## 文件与检查范围

- 原主壳参考外形125×78×106 mm；与4.3英寸顶部屏幕、Pi3B+、CM2及原控件的尺寸相关。
- 3MF 是原交付的拓竹 X2D / 0.4 mm喷嘴 / PETG Matte 示例，不是所有材料的默认配方。部分含原机器的切片 G-code；先以项目方式打开、检查对象并为自己的打印机重新切片，不直接发送内嵌G-code。
- V30试配例为0.12 mm层高；主结构等示例为0.16 mm。材料、机器、方向或缩水不同，间隙与手感可能不同。
- 来源记录中的切片或几何检查通过，不代表新读者的实物装配、胶接、电池线根余量、供电或长期寿命通过。遇阻先停止该步骤，核对零件版本和实际尺寸。
- Blender装配可能含硬件代理和示意对象；可打印件以相应STL和零件清单为准，不能把装配场景里的每个网格都当作打印件。
