此目录是另一款外观方向，暂定125×78×42 mm，不是原125×78×106 mm方盒相机。未完成Pi、屏幕、电池内部布置、掏空和制造适配。

- [参考相机 R01 · FreeCAD 源文件](Junshu_Reference_Camera_R01_ViewFixed.FCStd)：经过GUI保存可见性的30件FreeCAD原生实体。
- [参考相机 R01 · STEP 交换文件](Junshu_Reference_Camera_R01.step)：同源实体交换文件。
- source/build_cad.py、parameters.json：尺寸与几何重建源。脚本最初按Mac安装路径编写，应在匹配的FreeCAD Python环境使用，先另存副本；重建后还需GUI设置可见性并保存。

这是可编辑几何，非完整的参数特征树。没有附广告动画、视频工程、屏幕照片纹理或视频制作资料。自有几何采用CC BY 4.0。
