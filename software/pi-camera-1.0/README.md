# New Cam · 1.0.0

这是Junshu指定命名的正式1.0版本，以已使用的R4 0.4.0功能为基础，加入正式New Cam开机图、启动定位修正及从开机画面进入相机的衔接。版本命名不代替实机验收：本机Plymouth/DSI的实际显示位置、黑屏间隔和桌面是否完全不露出，需要下一次实际开机观察。

## 使用

在Mac运行随交付提供的“安装NewCam1.0.command”，按提示选择已信任的树莓派，SSH/sudo密码只在终端私下输入。导入器核验两个发布包、保留启动设置和映像备份，配置以后开机使用1.0；不会自行重启或停止正在使用的相机。安装明确成功后，用已有按钮正常关机，再按按钮开机。

在树莓派桌面可用New Cam 1.0图标再次打开。普通SSH没有触屏会话，不用于启动相机GUI。需要本地终端启动时执行：

```
cd /home/junshu/junshu-camera-pi-1.0.0
/usr/bin/python3 -B check_package.py
sh ./start-camera.sh
```

## 开机与退出

系统仍保留LightDM/labwc桌面。用户级启动入口先启动相机，延后桌面图标/面板；相机先展示与开机阶段相同的New Cam图，准备好实际预览并完成首次绘制后交接。只有一张静态图片，没有“测试”“正在启动”等占位文字，也不为了Logo刻意延时。正常退出后启动桌面组件，相机不会自动重复打开；异常应留下日志并提供桌面恢复路径。

本版不改专用DRM或无桌面架构。启动阶段显示驱动交接可能短暂黑屏，不能只凭本地校验承诺逐帧无闪动。

## 数据与现有功能

- 照片继续使用 `~/Pictures/JunshuCamera/photos/`，设置继续使用 `~/.config/junshu-camera/settings-r4.json`。
- 保留普通拍照、比例/全屏/设置保存、图库、L1拉杆、既有三秒按钮关机与留电唤醒、系统白灯及同Wi-Fi手机传图。
- 原照片和旧安装目录保留。1.0与旧版共用相机实例锁，避免同时占用相机。
- 本版不重装电源服务，不热改GPIO，不改接线、Wi-Fi、分区或系统包。
- 未检测到电量读数时显示未知；不启用按开机时长估算电量。HDR仍按已确认的预留行为使用普通模式；iPhone直接导入“照片”继续暂缓。

## 升级与回退

应用与开机素材分别位于 `junshu-camera-pi-1.0.0` 和 `junshu-camera-boot-1.0.0`，由同一个Mac安装入口协调。主题升级会核对已有0.1.1真实文件、状态和备份；未知变更时停止并保留报告。

Mac的“回退NewCam1.0.command”按本轮备份恢复升级前启动链及开机画面；文件与备份均保留，不删除旧/新应用或照片。回退也不会自动重启。若安装中途报错，请保留完整输出；不能把“已传入文件”当作所有配置已完成。

更多功能边界见 `feature-status.md`，验证范围见 `TESTING.md`。
