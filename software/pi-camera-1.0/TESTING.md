# New Cam 1.0.0 验证边界

正式Logo取自用户原文件，应用与Plymouth使用相同字节；不重新生成或裁切图片。旧0.4.0与boot0.1.1发布包保持原校验值。

本地检查涵盖：不同启动输出尺寸/顺序/原点变化时的居中；静态不重复缩放；密码提示和关机画面；加载页至有效预览绘制的交接；退出/错误/超时；用户级启动配置的备份、重复启用、拒绝未知变更和回退；从已启用0.1.1升级正式主题的映像与文件恢复；归档清单与SHA及导入拒绝路径。具体运行结果以Mac项目 `qa/newcam-1.0-20261028/` 的最终verification.json为准，不把测试计划当成已通过结果。

测试在Mac保留夹具内运行，不接GPIO、真实CM2或更改Pi。Plymouth主题控制逻辑通过语法适配检查，不等于原生Plymouth渲染；Qt离屏渲染不等于Wayland/DSI实屏效果。Linux专有机制在Mac无法验证时单独标注。

用户不需要再安装一个占位测试版。正式1.0安装成功后正常开机观察即可：New Cam居中、未露桌面而进入取景；退出能回桌面并从图标重开；原拉杆拍照、按钮/白灯与手机传图仍可用。程序不会自动关机、重启或替用户触发拍摄。

出现问题保留Mac报告和Pi的 `~/.local/state/junshu-camera/` 日志，通过随交付的Mac回退入口恢复本轮改变的启动设置；不要删除安装目录或备份。
