# New Cam 1.0.0 功能状态

1.0是本次正式发布编号。本地软件检查、此前用户实测和本次实机验收分别记录，不能互相代替。

| 能力 | 本版范围与证据 | 仍需确认 |
| --- | --- | --- |
| 正式开机图 | 原样采用用户480×800 New Cam PNG，单张静态；按目标输出尺寸和原点居中 | 新版实机位置和启动阶段显示切换 |
| 进入相机 | 保留labwc，延迟桌面/面板；早期全屏Logo，首个有效预览绘制后交接 | 实机是否还露出桌面及退出/异常桌面恢复 |
| 拍照/图库/设置 | 继承0.4.0，继续使用原照片/设置目录 | 1.0实机回归，不重新宣布所有相机功能完成 |
| 拉杆L1 | 保留GPIO17去抖、一次拨动一张及忙时不积压 | 用户此前测试通过；本版启动变化后回归 |
| 按钮和白灯 | 保留现有GPIO3电源服务和GPIO22内核灯；不重装、不改线 | 用户此前运行/退出/关机/再开机实测正常；1.0回归 |
| 手机传图 | 相机选图、二维码、iPhone可减选、下载JPG/ZIP | 用户此前传图成功；新版本回归 |
| iPhone直接入照片 | 不新增；仍通过文件下载后由用户存储图像 | 按用户决定延期 |
| 电量 | 现有读数接口；无读数显示未知 | 等待硬件检测，不做60分钟估算 |
| HDR/RAW | HDR按用户决定预留，正常/HDR均普通拍照；RAW仍按现有能力提示 | 不以1.0编号宣称真实HDR或RAW完成 |
| 性能 | 保留0.4.0预览工作线程、有界图库与直方图节流 | 真实Pi3B+帧率/触控仍以设备反馈为准 |
| 发布回退 | 两个独立版本包、完整校验、原状态备份、Mac统一入口 | 实机安装与回退显示效果 |

运行日志、已核验文件和测试记录随Mac项目保留。没有自动删除照片、重装系统或扩大GPIO功能。
