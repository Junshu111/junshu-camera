# 硬件与购买参考

本次方盒相机参考组合：Pi3B+、Camera Module 2 / IMX219、4.3英寸480×800 DSI屏、独立拍照拉杆和电源按钮。后续V31电池盒按48×40×20 mm电池制作；旧结构基线有不同电池尺寸，先看models/README.md。

- [采购核对表 CSV](../docs/downloads/chapter-04-table.csv)
- [端子与接线核对表 CSV](../docs/downloads/chapter-10-table.csv)
- [认识零件](https://junshu111.github.io/junshu-camera/chapters/02.html)
- [连接与供电](https://junshu111.github.io/junshu-camera/chapters/05.html)
- [元器件接线](https://junshu111.github.io/junshu-camera/chapters/10.html)

这些是原项目的型号、接口和验证记录，价格与购买链接仅作线索；读者按实际在售规格、排线方向、模块外形和电气参数重新核对。没有在此次发行中设计或提供一块新的自定义PCB；教程中的主板系统准备不能理解为任意PCB的通用激活步骤。

软件中的L1为BCM17输入，电源服务参考BCM3；物理针号与BCM编号不能混用。按钮灯、电源、屏幕和相机接法须看完整说明和实际模块，先断电核对，不仅凭线色、照片或这份摘要接电。更换零件后，原打印件与接线不保证直接适配。

硬件实物尺寸与自己的检查结果记录到 .camera-work/STATUS.md；原材料PETG Matte和X2D示例不替代读者本次材料与机器选择。
