开始制作前 / 先让 AI 帮你准备

两次复制，
让 AI 帮你开始。

把项目链接和下面这段话发给 AI。
先选项目、准备分工，再一步一步开始。

01

把 GitHub 链接发给 AI。

复制链接 → 粘贴到 AI 对话框 → 发送。

GitHub 项目链接https://github.com/Junshu111/junshu-camera
02

再把这段话发给 AI。

复制完整提示词 → 发到同一个对话框。

发给同一个 AI 对话框

我是新手，想跟着自制相机教程制作自己的相机。仓库：https://github.com/Junshu111/junshu-camera
请先实际获取并阅读 README.md、AGENTS.md、GETTING-STARTED.md 和 AI-WORKFLOW.md；读不到时说明原因，一次给我一个补救操作。
第一条回复请先用简单中文展示“00 总工作台＋A—F 专项对话”的文字分工图，并只让我选：A 新建独立项目和七个对话（推荐）；B 在当前项目准备七个对话。等我选择后再创建或操作。
我选择后，请按仓库流程创建或复用这些用户可见对话，逐个发送启动交接、核对真实就绪回复；不能自动建项目或对话时，就一次一步教我手动创建，并给可直接发送的启动文字。不要假装已经创建，也不要把后台子代理算作这些对话；我要求先用一个对话时也可以。
然后回到总工作台，确认我的电脑系统与资料位置，先阅读教程、按已有工具做只读自检，再引导第一章。每次只讲一个动作、操作位置和完成标志。说明目前仓库已提供与尚缺的内容。本次只准备工作台和电脑端，不连接或写入树莓派、不接线、不购买、不打印。

↳AI 会先展示分工图，让你选新项目或当前项目，再帮你准备对话和电脑环境。

能自动创建时由 AI 完成；不能时，它会逐步教你手动创建。也可先用一个对话。
